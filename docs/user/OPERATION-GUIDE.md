# Chordesk 操作速查

iOS 正式版从 [App Store](https://apps.apple.com/app/id6828753865) 下载，当前为 1.34；公开配套主机为 Mac 0.28.0。直接安装或更新，无需 TestFlight；请以实际安装版本与设置为准。

默认直接触控、背面双指接触临时切换。普通 iPhone 可用右侧操控模式按钮。

<a id="recommended-settings"></a>

## 首次使用推荐设置

以下为手动设置建议，不代表每台手机当前的默认值；升级会保留已有偏好。先连接 Mac，再调整传输画质。

| 入口 | 选项 | 推荐 |
| --- | --- | --- |
| 菜单 → 快捷键设置 → 文字输入 | 键盘 | **iPhone 输入法**；系统键盘或已启用的微信等输入法 |
| 同上 | 键盘唤起 | **自动唤起**；未识别输入框时，点右下键盘按钮 |
| 同上 | 键盘弹出时适配远程画面 | **开启**，将画面等比例缩到键盘上方，方便核对输入 |
| 菜单 → 远程传输画质设置 | 视频编码 | **H.265**；出现兼容或显示异常时尝试 H.264 |
| 同上 | 传输分辨率 | **1080p** 起步，网络不稳时降到 720p／480p |
| 同上 | 帧率上限 | **30 fps** 起步，弱网可降到 15 fps |
| 同上 | 目标码率 | **1.5–2 Mbps**，常规使用建议不超过 2 Mbps；按实际连接下调 |
| 菜单 → 背屏控制设置（仅 Duo） | 模式切换 | 双指接触立即临时切换触控板，抬起恢复；普通 iPhone 使用右侧模式按钮 |

### 按网络调整

| 场景 | 传输分辨率 | 帧率上限 | 目标码率 |
| --- | --- | --- | --- |
| 日常办公起步 | 1080p | 30 fps | 1.5–2 Mbps |
| 网络波动、跨网中继或操作延迟升高 | 720p | 15–30 fps | 1 Mbps |
| 很弱的连接，优先保持可操作 | 480p | 15 fps | 0.5 Mbps |

这些是建议起点，不是流畅度保证。2 Mbps 是建议的**目标码率**，不是实际流量的硬上限；瞬时流量和协议开销可能更高。1080p 在低码率和大幅滚动时可能变糊，优先降低分辨率或帧率，给网络留出余量，不要用提高码率来解决延迟。

可在画质设置中检测当前 Mac→手机的连接，并选择“应用推荐码率与帧率”；推荐值仍需结合实际手感判断，且可能超过上述 2 Mbps 建议，应用后请核对。诊断信息可临时打开，观察实际 fps、Mbps 和 RTT；RTT 不等于完整操作延迟。

传输分辨率不改变 Mac 的文字大小。文字太小时，使用显示器菜单的文字大小／显示模式；键盘仍挡住输入区时，先确认“键盘弹出时适配远程画面”已开启。

## 0 指背屏（直接触控）

| 正面操作 | Mac 效果 |
| --- | --- |
| 轻点 / 双击 | 左键 / 双击 |
| 单指滑动 | 滚轮滚动 |
| 长按约半秒后拖动 | 按住左键拖选，抬手释放 |
| 长按不动，松手 | 右键菜单 |
| 双指捏合 / 平移 | 仅缩放 / 移动手机查看画面 |

## 1 指按住背屏（直接触控）

| 正面操作 | Mac 效果 |
| --- | --- |
| 双指上滑 / 下滑 | 打开 / 退出窗口总览 |
| 双指左滑 / 右滑 | 下一个 / 上一个桌面 |

切桌面需要至少两个桌面、系统 Control＋方向键快捷键，以及 Mac 主机设置中的 System Events 授权。

## 2 指接触背屏（临时触控板）

| 正面操作 | Mac 效果 |
| --- | --- |
| 单指滑动 | 移动鼠标 |
| 单指轻点 / 双击 | 左键 / 双击 |
| 单指长按后拖动 | 按住左键拖选 |
| 双指滑动 / 轻点 | 滚轮 / 右键 |
| 松开背面 | 恢复直接触控 |

键盘上方的黑边也能作为触控板，右侧快捷栏除外。右侧双段模式选择器可固定切换；背屏控制设置可改为“一次触发切换，再触发恢复”。

## 键盘与右侧快捷栏

侧栏三组原生玻璃支持按住／轻拖拉伸及回弹，已包含在 App Store 正式版中。

- 默认 iPhone 输入法、自动唤起。点击可编辑输入框后抬起手指；未识别时点右下键盘按钮。快捷键设置可改为手动唤起。
- 画面默认等比例贴在键盘上方；快捷键设置可关闭。系统键盘尺寸由 iOS 管理，自定义手机布局可调整高度与透明度。
- 长按系统键盘空格后滑动可移动 Mac 文本光标。第三方输入法需提供相应系统回调。
- 键盘按钮左侧的 Ctrl / ⌥ / ⌘ 可组合，下一次快捷键后释放，再点可取消。长按键盘按钮打开 Esc、Tab、复制粘贴、方向键和 F1–F12。
- 菜单 → **快捷键设置**可隐藏显示器、窗口总览或操控模式选择器，默认显示，已有偏好保留。上方为菜单及显示器／总览快捷键，其下为双段操控模式，底部是单个圆形键盘按钮；三组都可按住轻拖体验系统玻璃拉伸，松手回弹；横竖屏和仅外屏都保留在右侧，可上下滑动上方控件。总览按钮轻点打开，长按选择退出。

长按选字采用 iOS 原生放大镜，随落点移动，抬手或多指操作后关闭。菜单 → **辅助功能设置 → 选字放大镜**可关闭；不会修改 Mac 的缩放。

## 四类设置

| 入口 | 内容 |
| --- | --- |
| 快捷键设置 | 右侧三个快捷键、位置、输入法、自动 / 手动键盘、键盘适配画面、自定义键盘外观 |
| 背屏控制设置 | 启停背面、临时 / 锁定切换、触发动作、一指组合手势、可视化有效区域 |
| 远程传输画质设置 | 显示器与文字大小、视频格式、独立分辨率／帧率／码率、连接检测与推荐 |
| 辅助功能设置 | 操作手册、诊断信息、关于、触控方式、放大镜、灵敏度、惯性、震动、本地演练 |

**诊断信息 → 显示连接信息**可关闭画面上的分辨率、fps、Mbps、RTT，也可选择四角位置。RTT 是往返通信时间，不是触控到画面的完整延迟。

文字太小用显示器菜单调整 Mac 逻辑分辨率；画面模糊用传输画质。传输分辨率只改变视频像素，不改变 Mac 排列或文字大小。

| 传输选项 | 设置 |
| --- | --- |
| 分辨率 | 480p、720p、1080p、1440p、2160p；等比缩放、不放大源画面 |
| 帧率上限 | 15、24、30、60、90、120 fps，与分辨率独立 |
| 目标码率 | 0.5–80 Mbps，松开滑杆后应用；实际码率随画面变化 |
| 默认 | 720p、15 fps、1.5 Mbps、H.265；保留已保存的偏好 |
| 连接检测 | 测当前 Mac→手机路径，得到推荐后点“应用推荐码率与帧率” |

H.265 压缩效率通常较高，未必编码延迟更低；硬件不支持时回退 H.264／JPEG。测速载荷最多 512 KiB，另有少量协议开销，可能短暂影响画面，结果不是运营商带宽承诺。静止画面、源屏刷新率、网络及手机显示能力会限制实际 fps。Mac 逻辑分辨率调整仍可能改变实体屏幕，断开后尝试恢复。

## 初次连接与结束

Mac 按提示分别允许屏幕录制、控制权限；每次系统要求重启 App 时照做，两项生效后开启服务。手机首次扫码，之后点已配对 Mac；跨网需两端登录同一 Tailscale 私人网络。

Duo 保持展开、App 前台。背屏正常纯黑，仅编辑有效区域时显示边框。三盏灯表示有效区域内手指数；菜单收起后抬起背面手指再落下。

本开发版暂时停用麦克风采集、传输和 Mac 音频路由；iPhone 麦克风不会自动成为 Mac 麦克风。Mac 关窗口仍在后台监听；无手机观看时停止采屏与编码，已认证手机连接后再开始。正在远控时保留系统共享提示。停止服务或退出后不再接受连接。息屏不等于睡眠，真正睡眠或合盖不保证连接。
