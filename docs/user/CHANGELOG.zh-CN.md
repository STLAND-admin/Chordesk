## 已更新的内容

- 用户真机确认黑边、快捷键与菜单短按正常。保留现有黑底 App 图标。[验证](../developer/DEVELOPMENT-HISTORY.md#archive-validation-1-29)。

### 1. 跨网络访问与自动连接

- 两端内嵌 Tailscale 用户态网络引擎，不需要额外安装 Tailscale App 或系统 VPN。局域网免登录；跨网在 Chordesk 内登录各自的私人网络，不共用开发者账号。
- iPhone 使用系统认证窗口完成官方节点绑定；修正登录后误开官网、下载引导，以及同一表单行多个按钮同时响应的问题。只有节点就绪并获得私人地址才算绑定完成。
- 主机的 LAN 与已允许的 Tailscale 入口可同时运行；手机可选自动、仅局域网、仅 Tailscale，无需双端手动选同一个模式。
- 二维码及认证后的主机状态可携带两种地址，保存到同一已认证主机记录。以 hostID／配对密钥识别，不能只凭相同名称合并电脑。
- 自动模式并行验证两种路线。1.28 优先 Tailscale；局域网先成功时最多额外等 350 ms 就回退，公网已失败则立即采用可用 LAN。
- 新主机支持复用胜出候选的 TLS 连接，免去原自动模式“探测成功后关闭、再建连握手”的重复步骤。普通在线检查仍不能升级为远控；不抢占其他手机。
- 前台换网或连接中断后，先释放输入，再最多三次自动重选路线；手动断开与退后台取消。属于自动重连，不是无缝迁移。
- 新增已配对 Mac 的在线状态、检查时间，区分服务在线、显示器暂不可用、用户会话暂不可用和已有设备连接。超时不等于关机，本机 Tailscale 在线也不等于 Mac 可达。
- 状态文案显示实际 LAN／Tailscale；诊断页增加路线验证、连接是否复用和首帧总耗时。

### 2. 视频、带宽与性能可见性

- 新安装默认省流 **15 fps、最长边 1280**；保留已有画质偏好。15 fps 是请求上限，静止画面的帧率会降低。
- 从原来的逐帧 JPEG 新增 **H.264 硬件编码／解码**，使用实时、无帧重排和低延迟码率控制；保留 JPEG 兼容路径。
- 1.28 增加手动选择 **H.265 / HEVC**。使用硬件实时编码／解码与无帧重排，不支持或失败按 HEVC → H.264 → JPEG 回退；旧版可继续连接。
- 省流 H.264 初始目标 **1.5 Mbps**，HEVC **1.125 Mbps**；其他档 HEVC 为同档 H.264 预算的 75%。这是编码参数，不是固定流量上限或同等画质保证。HEVC 也可能适合弱网，不按“网络好才选 H.265”自动切换。
- 视频写入积压时丢帧，并通过关键帧与序号恢复；包长和像素有界，不无限排队。仍可能存在 TCP 和系统缓冲延迟。
- 可关闭的左上信息显示实际路线／编码、视频像素、接收 fps、视频载荷 Mbps 和应用往返 RTT。RTT 不是触控到画面的完整延迟。
- **AV1 未加入**；RDP／客户端渲染仍是研究待办。

### 3. 触控、滚动与键盘

- 直接触屏单指、触控板双指共用滚动惯性；设置系数 **0–2，默认 1**，0 关闭。Mac 统一执行减速，手机估算抬手速度。
- 重新落指、模式变化、菜单、断连或控制许可失效会取消惯性，避免旧滚动重新出现。
- 修正触控板双指分批抬起时误判为取消、导致没有惯性的路径；补充不记录文字的抬手速度诊断。该硬件问题的最终手感仍需复测。
- 键盘出现时，远程画面默认等比例放入键盘上方、底部贴住键盘，避免输入框被遮挡；可在设置关闭，收起后恢复。不会改变 Mac 分辨率，也没有重新加入本地文字输入栏。
- 键盘唤起／收起采用系统动画；修正唤起时画面跳变。键盘按钮与 Ctrl／Cmd／Option 贴键盘上沿，不再大幅上移。
- 修正键盘显示时直接触控／触控板输入层被移除或坐标不一致的问题；画面和输入使用相同区域，布局切换时释放旧接触。

### 4. 背屏与操作说明

- 正常使用时背屏纯黑，移除常驻说明文字、遮罩和有效区边框；**只有编辑有效区域时显示边框**。
- 背屏仍接收原区域内的一指／双指和弦，不关闭所需相机会话。纯黑不等于相机或显示硬件已断电，不承诺具体省电比例。
- 内置手册、仓库操作指南和网络说明持续同步。原有直接触控、触控板、一指窗口／桌面手势、双指临时切换、键盘、麦克风等说明保留。

### 5. Mac 首次使用与恢复

- 0.23.1 根据真实首次授权反馈，改为两个手动按钮：授权屏幕录制后按系统提示退出重开，再主动请求控制并按提示重开。没有系统提示时可用 App 重启按钮，部分授权也能手动重启。
- 取消自动连续请求、定时子进程预检与重启倒计时；仅两项均生效的进程可开启内置屏服务。拒绝或暂停不会反复请求或重启 Mac。
- build 36 修正“允许屏幕录制”未弹窗时缺乏反馈：未获授权就打开对应设置，显示当前 App 名称和手动路径；打开设置不等于授权成功。
- 修正退出清理／重启可能卡住的问题；先释放输入、恢复显示设置并停止网络，再退出，旧进程真正结束后才重开。
- 原共享显示器短暂离线时保留监听，有界等待／恢复原显示器；不自动共享另一屏，不恢复已被撤销的权限。
- 新会话缺少新画面时可有界重建原捕获流；睡眠／会话边界重建本应用输入源，不补发全局按键或自动输入密码。
- 试验性增加仅接电、已认证观看会话的网络活跃请求；**合盖仍未解决**。用户确认不输入密码也会卡住／断开，日志出现 Dark Wake／Clamshell Sleep，不能归为回车键问题。
- 提供独立 Mac／iOS **First Run** 测试副本：新的应用身份、空白设置、配对和 Tailscale 存储，保留日常版数据。Mac 测试包按版本命名、运行位置移出 Documents；文稿访问不是基础远控必需权限。

## 已确认与尚未完成

用户已确认：内嵌 Tailscale 蜂窝画面／触控；在线状态；1.27 键盘动画、按钮位置、键盘可见时两种触控；H.264 和蜂窝自动重连。

1.28 已通过 165 项完整逻辑／TLS 回归、最后 23 项针对性复查、两项模拟器 UI 回归；本机生成画面的 H.264／HEVC 硬件往返与格式切换通过。这些不等于真实 Duo HEVC、跨网建连提速、功耗或全部机型均已验证。

发行前仍需：完整首次授权及真实下载流程、固定触控板惯性、1.28 真机背屏与双编码、跨网络冷启动／长连接和性能、普通 iPhone 真机。合盖远控和按需采集能耗优化仍是未解决项。新版内嵌加密与第三方账号服务需要重新核对隐私及出口合规，不能沿用第一版“仅系统加密”申报。
