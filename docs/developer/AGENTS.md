# Chordesk 编码规范

本项目面向 iPhone Duo 的可变窗口与多显示区域体验。新增界面和修改布局时，必须遵守以下规范：

这些规则纳入了你提供的小红书笔记[《9条vibecoding规范让App完美适配iPhoneDuo》](https://xhslink.cn/o/2lqF0yJkGlm)，并结合了 [Apple 的 iPhone Duo 设计指南](https://developer.apple.com/design/human-interface-guidelines/designing-for-iphone-duo)。

1. 不用设备屏幕尺寸、像素阈值或固定宽度写布局；根据可用空间、大小类和系统布局信息排版。
2. 不按内屏/外屏或折叠姿态分支布局；让界面随可用尺寸变化。
3. 远程桌面的显示层在竖屏、横屏及仅外屏使用时均默认边到边，可延伸至 Wi-Fi／状态栏区域下方；不得用内容安全区裁切画面或人为留黑边，不用常量模拟系统边距。
4. 不把安全区作为远程画面或触控板的可交互边界。用户于2026-11-03进一步确认 Dock 在横屏、竖屏及仅外屏时均固定右侧，依据公开系统保留区域对齐 Wi-Fi 区域下方，不随方向迁到底部；状态条独立置顶。
5. 网格或瀑布流默认使用偶数列；选择奇数列时说明理由。
6. 导航栏、工具栏和标签栏使用系统组件，不手绘替代系统栏。
7. 系统控件使用公开容器与布局信息；远程画面延伸到系统栏下方已按第 3 条获用户授权，不需为此重复申请。其他强制改变系统栏位置的需求先说明理由并取得用户批准。
8. 带图标的工具栏项同时提供标题和 symbol，标题可以不显示在界面上。
9. 省略号 symbol 只用于溢出菜单；App 自定义溢出入口应并入系统溢出菜单。
