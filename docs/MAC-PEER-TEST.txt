Chordesk · Mac 主机 — 同学试用版
本安装包：Mac 0.27.1 / build 42；建议搭配 iOS 1.31 / build 40。
iOS 1.30 仍可使用基础远控；独立画质控制需要 iOS 1.31，实际可安装版本以 TestFlight 为准。

这是什么
这是 Apple Silicon（M1／M2／M3 等 M 系列）Mac 的已签名公证测试版。
要求 macOS 15.2 或更新；本轮实际构建／验证环境为 Apple Silicon、macOS 27。
Intel Mac 不适用。已有同学 Mac 跑通基础远控；新版逐项手动授权流程仍需真实首次安装复测。
App 与最终 DMG 均已 Developer ID 签名、Apple 公证并装订票据，Gatekeeper 检查通过。
接收者不需要 Xcode、源码、开发者账号或开发证书。

安装
1. 打开 DMG，把 Chordesk.app 拖到 Applications（应用程序）。
2. 从“应用程序”打开 Chordesk；当前已公证包不应依赖“仍要打开”来通过来源检查。
   首次确认与系统权限提示仍由 Mac 所有人本人处理。
3. 若提示无法验证、文件损坏／包含恶意软件，或电脑受学校／公司管理，
   先核对版本和下载摘要并反馈提示。不要关闭 Gatekeeper、SIP、清除隔离属性或绕过组织策略。
4. 建议把 App 固定放在“应用程序”；更新、换签名或改变位置可能需要重新授权。
   普通升级应先退出再直接替换 App，不需要先用第三方软件卸载。

升级故障与卸载
- 若显示 Keychain read failed (-25293)，这是钥匙串认证失败，与屏幕录制／控制独立。
  点“授权钥匙串并重试”，在 Mac 系统提示中本人确认；若有“始终允许”，核对请求来自 Chordesk 后选择，单次允许可能无法保留。
  仍失败可确认“重新绑定本机公网身份”；新地址可能需重新扫码，旧节点可在自己的 Tailscale 管理页移除。
- 旧授权开着但新版无控制权限：设置 → 维护与卸载，可重置本 App 的授权并重启，再逐项允许。
- 同一位置、同一 bundle ID 和固定 Developer ID 身份有助于延续升级授权；临时签名不能保证。
- Help（帮助）→ 卸载 Chordesk…，无损预检后选择保留数据或完整卸载，再点“卸载并退出”。
  App 会先停止服务、恢复显示模式并正常退出，再执行所选清理；无需导出工具或打开终端。
  App／数据移入废纸篓；删除配对／登录需重新绑定，不会重置整个登录钥匙串或其他 App。
  完整步骤：https://github.com/STLAND-admin/Chordesk/blob/main/docs/MAC-MAINTENANCE.md

首次连接：同学操作 Mac，你操作自己的 Duo
1. 两台设备连接到同一、允许设备互访的局域网。
   校园／访客 Wi-Fi 可能隔离设备；“能上网”不等于两台设备可互通。
   此试用版也可在两端 Chordesk 内登录自己的同一 Tailscale 私人网络。
   不需要额外安装 Tailscale App；公网仅承载本 App 的流量，可能通过加密中继。
   自动模式会检查保存的 IPv4/IPv6 地址；首次获得新地址可重新扫码一次。
   不需要设置路由器端口映射。
2. Mac 打开“Chordesk · Mac 主机”，在首次权限区域逐项点击：
   “1 · 允许屏幕录制” → 在系统中批准 → 按系统提示退出并重新打开 App；
   “2 · 允许控制 Mac” → 在系统中批准辅助功能／设备控制 → 再按系统提示重开。
   没有系统重启提示时，可以用“重启 Chordesk”按钮；只重启 App，不重启电脑。
   重开后继续尚未生效的一项；不会自动弹出下一项或倒计时重启。
   两项权限均生效后，默认自动开启内置屏服务，可在设置关闭自动开启。
   基础远控不需要文稿、桌面、下载或完全磁盘访问；不要从这些文件夹运行 App。

3. 默认使用内置显示器；无内置屏时使用主显示器。也可点“开始服务”。
   无手机连接时只保持服务在线，不采屏、不编码；认证手机连接后才开始共享。
   完整屏幕画面会显示在配对的手机上，先关掉不想共享的窗口。
4. 权限由 Mac 所有人确认；主界面不显示操作日志。权限、网络、配对重置、
   诊断及手动显示器选择都在“设置”中。之后通常直接从手机切屏／调整文字大小。
5. Duo 打开 Chordesk → 连接 Mac → 扫描 Mac 二维码，并允许本地网络访问。
   “配对后自动控制、切屏并适配 Duo”默认开启：成功配对后，
   当前 Duo 可操作所选屏幕并调整显示模式。Mac 主人可提前关闭此选项，
   然后在连接后手动开启控制。首次测试请用可丢弃文稿。
6. 以后可从 Duo 选择已配对的 Mac 重连。Mac 的局域网 IP 改变后可能需要重新扫码。

Duo 手势速查
- 直接触控模式：先在背面有效区按住一指，再用正面双指上下滑打开／退出总览。
- 保持同样组合，正面双指左滑去下一个桌面、右滑回上一个桌面。
- 首次使用左右切桌面：Mac 设置 → 桌面切换 → 允许桌面切换（System Events），
  由 Mac 所有人确认系统自动化提示。这是普通屏幕录制/控制以外的可选权限。
  若拒绝，可在系统设置 → 隐私与安全性 → 自动化中检查 Chordesk 对 System Events 的授权。
  授权后重新触发手势；失败动作不重放。也可在同一设置区域先用“测试上/下一个桌面”。
- Mac 需有至少两个桌面，并启用 Mission Control 的 Control＋左右方向键快捷键。
  桌面到达边缘不会循环；多屏时由 macOS 当前活动屏幕决定。菜单有相同操作入口。
- iOS 1.31 新偏好默认背面双指接触立即临时切到触控板，抬起恢复。长按仍可选；已保存偏好保留。
  普通 iPhone 用右侧模式按钮；无背面一指时，正面双指继续用于查看缩放。
- 可用分辨率档位显示高对比“应用”按钮，真正禁用时才变暗。

显示与依赖
- 默认目标为 1600×900 逻辑分辨率；非 16:9 屏保持比例，可用档位取决于系统。
- 内置后端不需要 BetterDisplay。支持安全标准模式及部分内置屏扩展缩放系列。
  若系统不提供安全档位或当前自定义模式无法确认恢复，保留当前分辨率并说明原因。
  可先在系统显示设置选择默认分辨率，再刷新可用模式。请把完整提示、Mac 型号、
  系统版本反馈给发送者。不会创建缺失的 HiDPI 档位；可用手机捏合缩放辅助查看。
- 不要求为初次手势测试安装 BetterDisplay 或音频驱动。
  已有 BetterDisplay 的用户可在断连并恢复原设置后选择兼容方案。
- 当前版本关闭麦克风采集与音频传输。搭配 iOS 1.31 可独立设置传输分辨率
  （480p/720p/1080p/1440p/2160p）、帧率上限（15–120 fps）和目标码率。
  新偏好默认 720p、15 fps、1.5 Mbps，HEVC；已有选择保留，不支持时回退 H.264/JPEG。
  帧率和码率是请求目标，不是性能保证；传输分辨率不会改变 Mac 的文字大小。
  可在当前连接做限量测速，手动应用推荐码率与帧率；不是外部宽带测速。

结束共享
- 手机断开或退后台后停止采屏和编码，Mac 服务仍在线，已配对手机可再次连接。
  真正远控期间仍保留 macOS 的屏幕共享隐私指示。
- Mac 点“停止服务”即可断开并停止监听。关闭窗口会继续在菜单栏后台运行；“退出 Chordesk”才完全退出。
- 配对设备连接时默认请求点亮显示器，不跳过锁屏密码。可保持接电不自动睡眠，
  到时间只关闭显示器；真正睡眠、合盖、注销和重启后未登录不保证可连接。
- 扫码凭据可长期重连；不要把二维码发到群里或公开反馈中。
  结束借用后，Mac 主人可停止服务，并在设置的网络与配对中点“重置配对密钥”，使此前配对失效。
- 断连／正常退出会尝试恢复本次改变的分辨率及原屏幕排列。
  失败时保留记录并可重试；强制结束、掉电或拔掉显示器可能推迟恢复。
