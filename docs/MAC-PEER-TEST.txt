Chordesk · Mac 主机 — 同学试用版
Mac 0.18.1 / build 26；搭配 Chordesk Duo 1.21 / build 25。

这是什么
这是 Apple Silicon（M1／M2／M3 等 M 系列）Mac 的未公证测试版。
要求 macOS 15.2 或更新；本轮实际构建／验证环境为 Apple Silicon、macOS 27。
Intel Mac 不适用。已有同学 Mac 跑通基础远控；本版首次授权自动重启流程仍需复测。
使用本地代码签名，未取得 Apple Developer ID 身份验证或公证。
接收者不需要 Xcode、源码、开发者账号或开发证书。

安装
1. 打开 DMG，把 Chordesk.app 拖到 Applications（应用程序）。
2. 从“应用程序”打开 Chordesk。若提示开发者无法验证或未检查恶意软件，
   先关闭提示，再到“系统设置 → 隐私与安全性”，找到 Chordesk 的拦截记录，
   点击“仍要打开”，由 Mac 所有人完成系统确认。
   仅在你确认文件来自可信的发送者、理解它能共享和控制电脑时放行。
3. 若没有“仍要打开”、提示文件损坏／包含恶意软件，或电脑受学校／公司管理，
   先把提示文字反馈给发送者。安装说明不要求关闭 Gatekeeper、SIP，
   也不提供清除隔离属性或强行绕过组织策略的脚本。
4. 建议把 App 固定放在“应用程序”；更新、换签名或改变位置可能需要重新授权。

首次连接：同学操作 Mac，你操作自己的 Duo
1. 两台设备连接到同一、允许设备互访的局域网。
   校园／访客 Wi-Fi 可能隔离设备；“能上网”不等于两台设备可互通。
   公开旧版只支持局域网；内嵌 Tailscale 开发版的跨网设置见 docs/TAILSCALE.md。
   不需要设置路由器端口映射。
2. Mac 打开“Chordesk · Mac 主机”，点击“开始服务”。首次会进入两项权限引导，按提示允许“屏幕与系统音频录制”
   （不同系统也可能叫“屏幕录制”），再点“允许控制”完成辅助功能／发送输入授权。
   如果第一项完成后 macOS 提示“退出并重新打开”，先选“稍后”，继续控制权限。
   主机定期检查，必要时用同一签名程序的新进程复查系统权限，避免旧进程缓存拒绝状态。
   权限全通过且未共享时倒数三秒自动重启 App 一次；不会循环重启。
   可以关闭自动重启；两项均显示允许后，也可点“重启并开启服务”。缺少任一项不会重启。
   不会重启 Mac。默认在启动 App、权限就绪后开启内置屏服务；可在设置关闭自动开启。
3. 默认使用内置显示器；无内置屏时使用主显示器。也可点“开始服务”。
   完整屏幕画面会显示在配对的 Duo 上，先关掉不想共享的窗口。
4. 权限由 Mac 所有人确认；主界面不显示操作日志。权限、网络、配对重置、
   诊断及手动显示器选择都在“设置”中。之后通常直接从手机切屏／调整文字大小。
5. Duo 打开 Chordesk → 连接 Mac → 扫描 Mac 二维码，并允许本地网络访问。
   “配对后自动控制、切屏并适配 Duo”默认开启：成功配对后，
   当前 Duo 可操作所选屏幕并调整显示模式。Mac 主人可提前关闭此选项，
   然后在连接后手动开启控制。首次测试请用可丢弃文稿。
6. 以后可从 Duo 选择已配对的 Mac 重连。Mac 的局域网 IP 改变后可能需要重新扫码。

新手势（Duo 1.21 + Mac 0.18.1）
- 直接触控模式：先在背面有效区按住一指，再用正面双指上下滑打开／退出总览。
- 保持同样组合，正面双指左滑去下一个桌面、右滑回上一个桌面。
- 首次使用左右切桌面：Mac 设置 → 桌面切换 → 允许桌面切换（System Events），
  由 Mac 所有人确认系统自动化提示。这是普通屏幕录制/控制以外的可选权限。
  若拒绝，可在系统设置 → 隐私与安全性 → 自动化中检查 Chordesk 对 System Events 的授权。
  授权后重新触发手势；失败动作不重放。也可在同一设置区域先用“测试上/下一个桌面”。
- Mac 需有至少两个桌面，并启用 Mission Control 的 Control＋左右方向键快捷键。
  桌面到达边缘不会循环；多屏时由 macOS 当前活动屏幕决定。菜单有相同操作入口。
- 背面双指长按仍临时切换触控板；无背面一指时，正面双指继续用于查看缩放。
- 可用分辨率档位显示高对比“应用”按钮，真正禁用时才变暗。

显示与依赖
- 默认目标为 1600×900 逻辑分辨率；非 16:9 屏保持比例，可用档位取决于系统。
- 内置后端不需要 BetterDisplay。支持安全标准模式及部分内置屏扩展缩放系列。
  若系统不提供安全档位或当前自定义模式无法确认恢复，保留当前分辨率并说明原因。
  可先在系统显示设置选择默认分辨率，再刷新可用模式。请把完整提示、Mac 型号、
  系统版本反馈给发送者。不会创建缺失的 HiDPI 档位；可用手机捏合缩放辅助查看。
- 不要求为初次手势测试安装 BetterDisplay 或音频驱动。
  已有 BetterDisplay 的用户可在断连并恢复原设置后选择兼容方案。
- Duo 远程麦克风默认关闭。本次先测画面、触控、键盘和背面和弦。

结束共享
- Mac 点“停止服务”即可断开。关闭窗口会继续在菜单栏后台运行；“退出 Chordesk”才完全退出。
- 配对设备连接时默认请求点亮显示器，不跳过锁屏密码。可保持接电不自动睡眠，
  到时间只关闭显示器；真正睡眠、合盖、注销和重启后未登录不保证可连接。
- 扫码凭据可长期重连；不要把二维码发到群里或公开反馈中。
  结束借用后，Mac 主人可停止服务，并在设置的网络与配对中点“重置配对密钥”，使此前配对失效。
- 断连／正常退出会尝试恢复本次改变的分辨率及原屏幕排列。
  失败时保留记录并可重试；强制结束、掉电或拔掉显示器可能推迟恢复。

反馈
