# Chordesk 内嵌公网模式

开发版：iOS 1.23.1 / build 30、Mac 0.19.0 / build 27。当前公开 TestFlight 1.22.1 和 Mac 0.18.1 不含此功能；本轮只做本地构建与联调，跨网络验收见 [验证记录](VALIDATION-1.23.md)。

## 使用方式

- **局域网**：两端选“局域网”，照常扫码或点已配对 Mac，不需要账号，也不启动公网引擎。
- **公网**：两端只需 Chordesk，不另装 Tailscale。Mac 主机选“Tailscale 公网”，点“登录／连接 Tailscale”；iPhone 在“连接 Mac → Tailscale 公网”点同名按钮。官方登录页面可能跳转至你选择的身份提供商；在两端登录同一个个人账号并授权各自的 Chordesk 节点。需要设备审批的账号还要在 Tailscale 后台批准。
- 在 Mac 打开“允许通过我的 Tailscale 连接”，并开启远控服务。Mac 显示公网模式的二维码后，用手机扫描。首次公网与首次局域网分别配对；两种地址均可记住，已验证的主机身份相同时合并为同一台 Mac。
- 完成一次绑定后，可以让手机用蜂窝网络、Mac 用家中 Wi-Fi，再在公网页点已配对 Mac。网络变化不改变已保存的 Tailscale 节点地址；节点删除重建、账号切换或配对密钥重置则需要重新绑定。
- “断开公网”保留登录记忆；“退出账号”撤销此节点登录，局域网配对保留。手机退到后台停止远控并挂起公网节点；回到前台可恢复节点，仍需点选 Mac 重连。

### iPhone 登录后出现下载提示

无需安装官方 Tailscale App。Chordesk 自带节点；登录网页账号与批准该节点加入网络是两件事。1.23.1 使用系统 `ASWebAuthenticationSession` 完成官方网页认证，并以引擎的 `Running` 状态及已分配的 `100.x` 地址确认连接，网页跳转／关闭不算成功。

1. 在“连接 Mac → Tailscale 公网”打开登录，使用与 Mac 相同的账号／私人网络，确认本机名称 `chordesk-iphone`。
2. 若进入下载／安装页面，关闭认证窗口，点“检查绑定状态”。已经显示“已连接我的 Tailscale 私人网络”和 `100.x` 地址时，可继续扫描 Mac 的公网二维码。
3. 尚未绑定时点“继续绑定这台设备”。App 向当前节点请求继续授权，重新打开设备绑定链接，保留官方网页登录会话；无需退出账号或删除节点。
4. 若提示等待设备审批，在 Tailscale 管理页批准该设备。不要把尚待审批当作已连上，也不用重新注册。

认证时短暂切换到验证码应用，可获得系统允许且最长 20 秒的后台收尾时间；到期停止节点，返回后再继续绑定。远控、相机和输入始终在退后台时停止。此机制不是常驻后台 VPN，也不保证长时间离开后原登录窗口仍有效。

实现依据：[官方 tsnet 网页设备授权](https://tailscale.com/docs/features/tsnet/how-to/create-basic-tsnet-app)、[官方内嵌 iOS 认证示例](https://github.com/tailscale/aperture-plus/blob/main/TSNet/AuthManager.swift)。用户报告 Mac 登录可用、iPhone 登录后显示下载页；修正版真实账号登录仍需回归，不能据此认定已确定唯一原因。

不同人使用各自的 Tailscale 账号与私人网络，不把所有 Chordesk 用户加进开发者账号。一个人可以保存多台自己的 Mac，一次控制一台。第一版只接受节点的 `100.64.0.0/10` IPv4 地址，不接受域名、普通公网 IP 或 IPv6。已有的系统 Tailscale 客户端节点与 Chordesk 内嵌节点不是同一个节点。

## 连通方式与限制

采用官方开源 [tsnet](https://tailscale.com/kb/1244/tsnet) 用户态引擎，固定版本 `tailscale.com v1.104.1`，嵌入两端 App。它为 Chordesk 自身创建网络节点，不安装系统 VPN、驱动或后台守护进程，不代理其他 App 流量。主机关闭窗口保留菜单栏服务；退出 App 才停止。手机退后台不承诺持续在线。

不需要你自租服务器或固定公网 IP，但会使用 Tailscale 的身份协调、穿透和必要时的中继基础设施。优先直连；中继回退不保证达到局域网的码率、帧率或延迟。大陆不同运营商、企业网、校园网及严格 NAT 必须实测，不能承诺“任意网络必通”。Mac 真正睡眠、关机、退出登录或没有网络时也不保证可达。

[Personal 当前价格](https://tailscale.com/pricing)为 $0，最多 6 位用户、用户设备不限数量，须符合个人计划适用条件。每位使用者自己的账号分别受其条款约束；这不是 Chordesk 获得无限免费 OEM／商业托管服务的承诺。未来商业分发或统一代管账号需另行核对 [服务条款](https://tailscale.com/terms)及 OEM 方案。

## 配对与隐私

Tailscale 登录不替代 Chordesk 配对。两端仍用随机密钥和 TLS 1.2 PSK 验证；只有当前已认证会话才能按 Mac 偏好开启控制。Mac 的系统权限、切屏限制、断连释放和旧输入丢弃均保留。

公网引擎只转发 TLS 密文。Mac 私人网络监听固定 49173，转到仅本机可达的临时 TLS 端口；手机用仅本机可达、单次使用的临时端口接入。没有向普通公网网卡开放服务，没有端口映射、Funnel、任意代理目标或开发者共享密钥。

节点私钥／登录状态存系统 Keychain，保存失败即报错，不退回明文文件；配对密钥也继续使用原 Keychain。官方登录链接只从引擎返回且校验为 `https://login.tailscale.com`，不把密码或验证码交给 Chordesk。应用目录仅保存引擎运行所需辅助数据，排除备份；不要公开该目录或完整登录链接。

启用公网会向 Tailscale 提交账号、节点标识、公钥与网络连接元数据，受其 [隐私政策](https://tailscale.com/privacy-policy)约束。代码关闭 SDK 日志上传，不代表消除了协调服务需要的元数据。Tailscale 无法解密端到端传输的桌面内容；本 App 另保留 TLS。App 不增加广告、跨 App 跟踪或录屏存档。隐私清单已加入此可选服务的账号／设备／网络元数据类别，正式上传前仍需同步 App Store Connect 和公开隐私说明。

## Mac 首次使用

点一次“授权并开启服务”，App 顺序请求屏幕录制、辅助功能／设备控制。用户在 macOS 系统提示中确认；可能仍需进入系统设置或本人验证，App 不能代点批准。每个缺失权限每次流程只请求一次，拒绝后等待用户处理，不反复弹窗。

授权完整后，使用同一签名程序的新进程只读复查，空闲时倒计时 3 秒、自动重启 Chordesk 一次，继续共享内置显示器。可暂停或取消；不重启 Mac，不清除 TCC，不更改锁屏。两项权限已生效时直接开启服务，不再要求通过系统共享选择器手动选屏。macOS 自己周期性要求的再次确认不能由 App 绕过。

## 构建与后续发布

见 [开发说明](DEVELOPMENT.md)。两端共用 `Native/Tailnet` Go/C 源码、版本锁与 Keychain 存储；XCFramework 从源码生成，未把依赖二进制提交到 Git。第三方许可随两端 App 提供于“关于 → 第三方组件许可”。

**本版引入了 WireGuard／Go 加密代码。**下次发行必须重新核对 Apple 出口合规问卷和隐私申报，不能沿用 1.22.1 的“只调用 Apple 系统加密”分类；不把本地开发签名安装等同于 TestFlight 已更新。参见 [Apple 加密出口说明](https://developer.apple.com/documentation/security/complying-with-encryption-export-regulations)。
