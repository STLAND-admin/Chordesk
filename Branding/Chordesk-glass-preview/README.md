# Chordesk glass icon study

**Selected: B / Frosted glass**, confirmed by the user on 2026-11-01.

- `Chordesk-frost.svg`: selected, transparent artwork preserving the B dual-surface geometry.
- `Chordesk-clear.svg`: lighter comparison variant.
- `desktop-preview.svg` / `.png`: simulated iPhone Home Screen and macOS Dock placements.
- `index.html`: local preview.

These are design mockups, not screenshots or system Liquid Glass rendering. Installed iOS / Mac icons remain unchanged in 1.29 / 0.24.0. A future production update should prepare layered assets in [Icon Composer](https://developer.apple.com/documentation/xcode/creating-your-app-icon-using-icon-composer), validate default/dark/clear appearances and platform exports, then replace the app assets.
